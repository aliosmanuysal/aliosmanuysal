## About me

I work with **Java and Spring Boot** for backend applications and **React and Next.js** for web interfaces. My repositories include database-driven desktop applications, REST APIs, and component-based frontend projects.

Beyond web development, my toolkit includes **Swift, Kotlin, Flutter, Python, Unity, and Supabase**, spanning mobile applications, game development, and backend services.

Through personal projects and **Patika.dev / Kodluyoruz** exercises, I practice object-oriented programming, relational data modeling, API integration, and state management. I also explore Web3 interfaces with TypeScript and Andromeda Protocol.
